## 1. 非機能要件一覧

| 項目 | 要件 |
|------|------|
| **ユーザー規模** | 20名以下の小規模システム |
| **認証セキュリティ** | パスワードはbcrypt等でハッシュ化して保存 |
| **認可** | サーバーサイドでロールチェックを実施（フロントのみの制御は不可） |
| **レスポンス** | 一般的な操作で3秒以内のレスポンス |
| **対応ブラウザ** | Chrome / Edge 最新版 |
| **言語** | 日本語 |

## 2. セキュリティ要件詳細

### 2.1 認証

- メールアドレス＋パスワードによるログイン
- パスワードはbcryptでハッシュ化して保存（平文保存禁止）
- 初期パスワードはシステムが自動生成（推測されにくいランダム文字列）
- 初回ログイン時にパスワード変更を強制する
- セッション管理はJWTを使用する

### 2.2 認可

- ロール（一般 / TL / 管理者）に基づくアクセス制御
- Spring Security によりサーバーサイドで権限チェックを実施
- フロントエンドのみの表示制御は補助的なものとし、APIレベルで必ず制御する

### 2.3 パスワードポリシー

- 初期パスワード（新規登録時）：ユーザーIDと同一の値を設定する。管理者がユーザーに口頭等で通知する
- パスワードリセット時：システムが一時パスワード（ランダム文字列）を自動生成し、管理画面に一度だけ表示する
- 初回ログイン時はパスワード変更を強制する（`InitialPasswordFilter` により他操作をブロック）

---

## 3. 性能要件

- 対象ユーザー数：20名以下の小規模システム
- 通常操作（一覧表示・入力保存）：3秒以内のレスポンス
- 同時接続ユーザー数：最大20名を想定

---

## 4. 可用性・運用要件

- ホスティング：AWS EC2
- データベース：AWS RDS（PostgreSQL 16.4）
- バックアップ：RDSの自動バックアップを利用（設定はインフラ設計で定義）
- ログ：アプリケーションログをEC2上に出力

---

## 5. 実行環境要件

| コンポーネント | 対応バージョン | 備考 |
|---|---|---|
| Node.js | 20.x（20 LTS） | Vite 8 / Vitest 3 / jsdom 26 が Node.js 18 非対応のため 20 以上が必須 |
| Java | 21（LTS） | バックエンド（Spring Boot）のみ |
| PostgreSQL | 16.4 | ローカル: Docker コンテナ、本番: AWS RDS |
| CA 証明書 | 社内ルートCA証明書（`company-root-ca.cer`）の Docker コンテナへの自動組み込みをサポート | `infra/certs/` に配置し `.env` の `CA_CERT_ENABLED=true` で有効化 |

## 6. 監査ログ要件

以下の操作について、操作者・操作日時を記録する。

| 操作種別 | 対象 |
|---------|------|
| 作成・更新・削除 | ITスキルマスタ、参考資格マスタ、ADマスタ、分類マスタ、レベルマスタ |
| 作成・更新・削除 | ユーザー、年度マスタ |
| カスタムスキル昇格 | ITスキル、資格 |

### 6.1 スキル可視化

> **ステータス**: 機能要件 3.18「グラフ表示（ダッシュボード可視化）」として第1フェーズで実装済み。  
> 以下は当初の想定。実装仕様は機能要件定義書 v2.1.0 を参照のこと。

実装した主な仕様:
- **レーダーチャート**: ITスキルレベルを分類1別にレーダーチャートで表示（今年度・前年度の比較）
- **成長グラフ**: 年度別・分類1別スコアの積み上げ棒グラフ
- **ヒートマップ**: 分類1×分類2別の採点平均を色で表現
- **ラーニング・タイムライン**: 資格取得・セミナー受講実績と今後の目標を時系列表示
- グラフライブラリ: Recharts を使用
- データ集計API: `/api/charts/radar`, `/api/charts/growth`, `/api/charts/heatmap`, `/api/charts/timeline`

---

### 6.2 データエクスポート / レポート

棚卸結果を社内の他システムや分析ツールで活用できるよう、出力機能を提供する。

| 機能 | 概要 |
|------|------|
| **CSV / Excel 出力** | ユーザー・年度を指定して棚卸データをエクスポート |
| **チーム集計レポート** | チーム単位のスキルレベル平均・分布を一覧出力 |
| **全社集計レポート** | 管理者向けに全社のスキル状況を集計・出力 |

---

### 6.3 TL面談記録

> **ステータス**: 機能要件 3.19「面談メモ機能（TL・管理者）」として第1フェーズで実装済み。  
> 以下は当初の想定。実装仕様は機能要件定義書 v2.2.0 を参照のこと。

実装した主な仕様:
- TL・ADMINが担当メンバーの棚卸照会画面から面談メモを記録（SCR-007 / SCR-008）
- 明細レベルのメモ（各ITスキル・資格・セミナー・目標行）と全体備忘録の2種類
- 入力者（TL/ADMIN）本人のみが照会・編集可能。社員本人も含め他ユーザーは閲覧不可
- `inventory_interviews` / `interview_detail_notes` の2テーブルで管理
