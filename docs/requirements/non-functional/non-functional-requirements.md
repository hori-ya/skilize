## 1. 非機能要件一覧

| 項目 | 要件 |

| **ユーザー規模** | 20名以下の小規模システム |

## 2. セキュリティ要件詳細

### 2.1 認証

- メールアドレス＋パスワードによるログイン
- パスワードはbcryptでハッシュ化して保存（平文保存禁止）
- 初期パスワードはシステムが自動生成（推測されにくいランダム文字列）
- 初回ログイン時にパスワード変更を強制する
- セッション管理はJWTを使用する

### 2.2 認可

- ロール（一般 / TL / 管理者）に基づくアクセス制御
- Spring Security によりサーバーサイドで権限チェックを実施
- フロントエンドのみの表示制御は補助的なものとし、APIレベルで必ず制御する

### 2.3 パスワードポリシー

- 初期パスワード（新規登録時）：ユーザーIDと同一の値を設定する。管理者がユーザーに口頭等で通知する
- パスワードリセット時：システムが一時パスワード（ランダム文字列）を自動生成し、管理画面に一度だけ表示する
- 初回ログイン時はパスワード変更を強制する（`InitialPasswordFilter` により他操作をブロック）

## 3. 性能要件

- 対象ユーザー数：20名以下の小規模システム
- 通常操作（一覧表示・入力保存）：3秒以内のレスポンス
- 同時接続ユーザー数：最大20名を想定

---

## 4. 可用性・運用要件

- ホスティング：AWS EC2
- データベース：AWS RDS（PostgreSQL 16.4）
- バックアップ：RDSの自動バックアップを利用（設定はインフラ設計で定義）
- ログ：アプリケーションログを `/var/log/skilize/application.log` に出力（日次ローテーション、30日保持、1ファイル最大100MB）

## 6. アプリケーションログ要件

### 6.1 ログ基盤

- フレームワーク: SLF4J + Logback（`@Slf4j` by Lombok）
- フォーマット: プレーンテキスト（開発・本番共通）
- 出力先: `ConsoleAppender`（開発）+ `RollingFileAppender`（本番: `/var/log/skilize/application.log`）
- ローテーション: 日次、30日保持、1ファイル最大100MB
- MDC付与: `requestId`（UUID）・`userId`（認証済みの場合）を全ログに自動付与（`LoggingFilter` で設定）

### 6.2 ログレベル定義

| レベル | 用途 |
|--------|------|
| ERROR | 5xx エラー・外部サービス障害・DB接続失敗等 |
| WARN | 認証失敗・権限エラー（4xx）・バリデーションエラー |
| INFO | 正常な業務操作（マスタ更新・ユーザー管理・棚卸提出 等） |
| DEBUG | 開発環境のみ使用。本番は INFO 以上のみ出力 |

### 6.3 INFOログ出力対象

以下の操作は INFO レベルでログを出力する（操作者・対象リソースを含める）。

| カテゴリ | 対象操作 |
|---------|---------|
| マスタ管理 | ITスキル・資格・ADセミナー・各分類・スキルレベル・年度マスタの書き込み操作（POST/PUT/DELETE/PATCH） |
| ユーザー管理 | ユーザー作成・更新・有効化・無効化・パスワードリセット |
| カスタムスキル昇格 | ITスキル・資格の昇格 |
| 棚卸 | 棚卸提出 |
| AI分析 | AI分析トリガー・完了・失敗 |

### 6.4 禁止事項

以下の情報はログに出力してはならない（機密情報漏洩防止）。

- パスワード・パスワードハッシュ（`password_hash`）
- JWTトークン（`Authorization` ヘッダの値）
- 氏名・メールアドレス等の個人情報

### 6.1 スキル可視化

> **ステータス**: 機能要件 3.18「グラフ表示（ダッシュボード可視化）」として第1フェーズで実装済み。  
> 以下は当初の想定。実装仕様は機能要件定義書 v2.1.0 を参照のこと。

実装した主な仕様:
- **レーダーチャート**: ITスキルレベルを分類1別にレーダーチャートで表示（今年度・前年度の比較）
- **成長グラフ**: 年度別・分類1別スコアの積み上げ棒グラフ
- **ヒートマップ**: 分類1×分類2別の採点平均を色で表現
- **ラーニング・タイムライン**: 資格取得・セミナー受講実績と今後の目標を時系列表示
- グラフライブラリ: Recharts を使用
- データ集計API: `/api/charts/radar`, `/api/charts/growth`, `/api/charts/heatmap`, `/api/charts/timeline`
