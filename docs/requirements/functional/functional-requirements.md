## 1. システム概要

社員が年次でスキルの棚卸を行うWebアプリケーション。  
棚卸は **ITスキル・資格・セミナー** の3種類で構成され、棚卸入力後に翌年度の **目標設定** を行う。  
前年度との比較・チームおよび全社のスキル状況の可視化を目的とする。  
ダッシュボードには棚卸結果をもとにしたグラフを表示し、**スキルの成長・バランス・学習活動の経年推移を視覚的に把握できる**ようにする。

## 3. 機能要件

### 3.1 認証・認可

- ユーザーIDとパスワードによるログイン・ログアウト
- ロール（一般 / TL / 管理者）に基づく画面・操作の制御
- セッション管理（JWT等）
- サーバーサイドでのロールチェックを必須とする（フロントのみの制御は不可）

---

### 3.2 棚卸入力

棚卸は **ITスキル・資格・セミナー** の3種類で構成される。年度ヘッダー（棚卸）は共通とし、入力画面はタブ等で切り替える。  
今年度分は**常に編集可能**とする（入力期間による制限は設けない）。  
入力は一時保存（下書き）と提出（確定）の2段階とし、提出後も再編集・再提出できる。  
**入力画面では前年度の入力値を一切表示しない**（前年度に引きずられず直観的に自己評価してもらうことを意図する）。

#### 3.2.1 ITスキル入力

- ITスキルマスタの一覧を**分類1**でグルーピングして表示する（分類2・3は表示しない）
- 各スキルに対して以下を入力する
  - **採点（数値）**：レベルマスタで定義された数値から選択
  - **備考**：採点根拠（任意テキスト）
- **カスタムスキル入力**：マスタに存在しないスキルをユーザーが自由に追加できる
  - スキル名・採点・備考を入力
  - カスタムスキルは入力者本人にのみ表示される
  - マスタ昇格はTL / 管理者が主導で行う（後述 3.8）

#### 3.2.2 資格入力

- 参考資格マスタの一覧を**資格分類**でグルーピングして表示する（未分類の資格はグループなしで表示）
- 各資格に対して以下を入力する
  - **取得年月**：年月（任意。未取得の場合は空欄）
  - **備考**：取得理由（任意テキスト）
- **カスタム資格入力**：マスタに存在しない資格をユーザーが自由に追加できる
  - 資格名・取得年月・備考を入力
  - カスタム資格は入力者本人にのみ表示される
  - マスタ昇格はTL / 管理者が主導で行う（後述 3.9）

#### 3.2.3 セミナー入力

セミナーは **AD**（ADマスタ管理）と **セミナー**（社外等の自由入力）の2種類とする。

- **AD**：ADマスタの一覧を**ADセミナー分類**でグルーピングして表示する（未分類のADはグループなしで表示）。各ADに対して以下を入力する
  - **受講年月**：年月（任意。未受講の場合は空欄）
  - **備考**：受講理由・振り返り（任意テキスト）
- **セミナー**（AD以外）：ユーザーが自由に追加できる
  - セミナー名・**分類**（セミナー分類マスタから選択。任意）・受講年月・備考を入力

#### 3.2.4 保存後の前年度比較・振り返り促進（ITスキル）

保存操作（一時保存・提出いずれも）の後、以下のフローを行う。

1. **前年度比較画面へ遷移**：ITスキルの当年度採点と前年度採点を横並びで表示する
   - 前年度データが存在しない場合（初回棚卸）は比較画面を省略する
2. **差分の強調表示**：前年度から採点が変化しているスキルを視覚的に識別表示する
3. **備考入力の促進**：採点が変化しているスキルのうち備考が未入力のものに対して記入を促すメッセージを表示する
   - ユーザーはその場で備考を追記・保存できる
   - 入力は任意であり、未記入のまま離脱することもできる

---

### 3.3 前回目標の振り返り

前年度に設定した目標に対して、当年度の棚卸提出後（`PENDING_GOAL`）に振り返りを行う。

- **振り返りが必要な条件**：当年度の棚卸が `PENDING_GOAL` 状態で、かつ前年度に目標設定が存在する場合
- 振り返りが必要な場合、棚卸提出後および `PENDING_GOAL` 状態でのログイン時に、目標設定画面より先に振り返り画面へ遷移する
- 振り返りが完了すると（`goal_review_completed_at` が記録される）、目標設定画面へ遷移する
- 前年度の目標が存在しない場合は振り返り画面をスキップし、直接目標設定画面へ遷移する

#### 3.3.1 振り返りの入力項目

前年度の各目標に対して以下を入力する（入力は任意）：

- **達成状況**：達成 / 一部達成 / 未達成 から選択（`ACHIEVED` / `PARTIAL` / `NOT_ACHIEVED`）
- **振り返りコメント**：自由テキスト

入力結果は前年度の目標レコード（`inventory_goals`）に保存する。

---

### 3.4 目標設定

棚卸入力（提出）後、目標設定画面へ遷移する。**目標設定はスキップできない。**

#### 3.4.1 目標設定の必須フロー

棚卸のステータスは以下の3段階で管理する。

| ステータス | 意味 |
|-----------|------|
| `DRAFT` | 棚卸入力中（一時保存状態） |
| `PENDING_GOAL` | 棚卸提出済み・目標設定未完了 |
| `COMPLETED` | 棚卸・目標設定ともに完了 |

- 棚卸を**提出**すると `PENDING_GOAL` に遷移し、前回目標の振り返り（前年度目標がある場合）→ 目標設定画面へ自動遷移する
- 目標設定を保存すると `COMPLETED` に遷移する
- **ログイン時チェック**：当年度の棚卸ステータスが `PENDING_GOAL` の場合、ログイン直後に振り返り画面（前年度目標かつ未振り返りの場合）または目標設定画面へ強制遷移する（他の画面へのアクセスはブロックしない）

#### 3.4.2 目標の入力要件

目標は **ITスキル / 資格カテゴリ** と **ADカテゴリ** の2軸で入力する。

| カテゴリ | 入力目標数 | 対象 |
|----------|:----------:|------|
| ITスキル・資格 | 1件以上 | ITスキルマスタ / 参考資格マスタ / カスタムスキル / カスタム資格 から選択または自由入力 |
| AD | 2件 | ADマスタから選択 |

各目標の入力項目：
- **目標対象**：スキル名 / 資格名 / AD名
- **達成・予定時期**：年月
- **理由**：目標設定の理由・計画（任意テキスト）

目標設定の件数バリデーション（ハードバリデーション）：
- ITスキル・資格の目標が1件未満、またはADの目標が2件未満の場合は保存・完了操作をブロックし、エラーメッセージを表示する
- 一時保存は件数不足でも可能とする（`PENDING_GOAL` のまま維持）

---

### 3.5 棚卸照会

- 自分の棚卸結果と目標を**年度指定で照会できる**
  - 提出状態（下書き・提出済み）に関わらず、**全年度の入力結果を常に参照可能**とする
- ITスキルについて、年度を指定して前年度との比較表示を行う
  - 表示項目：スキル名、当年度採点、前年度採点、差分（増減）、備考
  - 当年度のみ登録（新規）・前年度のみ（未入力）を識別表示する
- 照会画面からも今年度分の備考を編集・保存できる

---

### 3.6 チームメンバー照会（TL）

- 自分のチームに所属するメンバーの棚卸結果・目標を照会できる
- メンバー・年度を指定して絞り込みができる
- 個人の前年度比較も参照できる

---

### 3.7 全ユーザー照会（管理者）

- 全ユーザーの棚卸結果・目標を照会できる
- ユーザー名・チーム・年度での絞り込みが可能

---

### 3.8 ITスキルマスタ管理（TL / 管理者）

- ITスキルの一覧表示・新規追加・更新。登録項目は以下の通り
  - **スキル名**
  - **分類1 / 分類2 / 分類3**：階層カテゴリ（後述 3.10）。分類1は必須、分類2・3は任意
  - **説明**・**表示順**
- **論理削除**：削除済みスキルはユーザーの入力・照会画面に表示しない
  - 既存の棚卸データに保存済みの明細には影響しない（データは保持）
  - 削除済みスキルは管理画面から復活（有効化）できる
- **カスタムITスキルのマスタ昇格**：
  - TL / 管理者は、棚卸照会画面でユーザーが入力したカスタムスキルを参照できる
  - 良いと判断したカスタムスキルをマスタに直接追加できる（ユーザーからの申請は不要）
  - 昇格時、対象ユーザーの棚卸明細はカスタムスキルから新規マスタスキルに自動的に紐付け直される

---

### 3.9 参考資格マスタ管理（TL / 管理者）

- 参考資格の一覧表示・新規追加・更新。登録項目：資格名・**分類**（資格分類マスタから選択。任意）・説明・表示順
- **論理削除**：削除済み資格はユーザーの入力画面に表示しない。既存データは保持。復活可能
- **カスタム資格のマスタ昇格**：
  - TL / 管理者は、棚卸照会画面でユーザーが入力したカスタム資格を参照できる
  - 良いと判断したカスタム資格をマスタに直接追加できる（ユーザーからの申請は不要）
  - 昇格時、対象ユーザーの棚卸明細はカスタム資格から新規マスタ資格に自動的に紐付け直される

---

### 3.10 ADマスタ管理（TL / 管理者）

- ADの一覧表示・新規追加・更新。登録項目：AD名・**分類**（ADセミナー分類マスタから選択。任意）・説明・表示順
- **論理削除**：削除済みADはユーザーの入力画面に表示しない。既存データは保持。復活可能

---

### 3.11 ITスキル分類マスタ管理（TL / 管理者）

- ITスキルの分類は**最大3階層**の木構造で管理する
  - **分類1**（大分類）：ユーザーの入力・照会画面に表示する
  - **分類2**（中分類）：管理・集計用途。ユーザー画面には表示しない
  - **分類3**（小分類）：管理・集計用途。ユーザー画面には表示しない
- 各分類ノードの追加・更新・論理削除が可能
- **分類削除時のブロック**：削除対象の分類（配下の分類含む）に有効なITスキルが1件でも存在する場合は削除不可とし、影響を受けるスキルの一覧を表示する
  - 管理者は対象スキルを別の分類へ移動するか、スキルを無効化してから分類を削除する

---

### 3.12 資格分類マスタ管理（TL / 管理者）

- 資格の分類をフラット（1階層）で管理する
- 登録項目：分類名・表示順
- **削除時のブロック**：削除対象の分類に有効な資格が1件でも存在する場合は削除不可とし、影響を受ける資格の一覧を表示する

---

### 3.13 ADセミナー分類マスタ管理（TL / 管理者）

- ADセミナーの分類をフラット（1階層）で管理する
- 登録項目：分類名・表示順
- **削除時のブロック**：削除対象の分類に有効なADマスタが1件でも存在する場合は削除不可とし、影響を受けるADの一覧を表示する

---

### 3.14 セミナー分類マスタ管理（TL / 管理者）

- セミナー（AD以外）の分類をフラット（1階層）で管理する
- 登録項目：分類名・表示順
- この分類を参照する棚卸明細が存在しても削除可能。削除後は対象明細の分類が未分類になる

---

### 3.15 レベルマスタ管理（TL / 管理者）

- レベルの一覧表示・追加・更新・削除
- 各レベルは以下の属性を持つ
  - **数値**（level_value）：整数。棚卸データへの保存値
  - **説明**（description）：例「知識がある」「経験がある」「実践できる」
  - **有効フラグ**（is_active）
- 数値・説明は変更可能だが、棚卸データに保存済みの数値は変更されない（参照時に最新マスタの説明を表示する）

---

### 3.16 ユーザー管理（管理者）

- ユーザーの一覧表示
- 新規登録（ユーザーID・名前・メールアドレス（任意）・ロール・TL）
  - 初期パスワードはユーザーIDと同一の値を設定する
  - 管理者がユーザーに口頭等で初期パスワード（＝ユーザーID）を通知する
- ユーザー情報の更新（ロール変更・TL変更含む）
- 有効化 / 無効化（論理削除）
- **初回ログイン時のパスワード変更強制**：初期パスワードでログインした場合、パスワード変更画面へ強制遷移し、変更完了まで他の操作を行えない

---

### 3.17 年度マスタ管理（管理者）

- 年度の一覧表示・新規作成・更新
- 各年度は以下の属性を持つ
  - **年度名**（例：FY2025）
  - **開始日** / **終了日**：会計年度の期間
  - **入力開始日** / **入力締切日**：棚卸の推奨入力期間（参考情報。システムによる入力ロックは行わない）
  - **有効フラグ**
- **年度区切り設定**：会計年度の開始月（デフォルト4月）を設定マスタで管理し変更可能

---

### 3.18 グラフ表示（ダッシュボード可視化）

#### 3.18.1 概要・表示位置

ダッシュボード（SCR-002）に以下4種のグラフコンポーネントを追加表示する。  
グラフはページ内に縦並びで配置し、既存のダッシュボード情報（棚卸ステータス・件数サマリ）の下に追加する。  
グラフデータの取得はダッシュボード表示時にバックグラウンドで行い、ローディング中はスケルトン表示または「読み込み中...」を表示する。

#### 3.18.2 対象データスコープ

| ロール | 表示内容 |
|--------|---------|
| 一般 | ログインユーザー自身の棚卸データ |
| TL | 自分のデータ（デフォルト）。切り替えにより**チーム集計**（自分のチームメンバーの集計）も閲覧可能 |
| 管理者 | 自分のデータ（デフォルト）。切り替えにより**チーム集計**・**全社集計**も閲覧可能 |

> **Phase 1 スコープ**：初期実装ではログインユーザー自身のデータのみを表示する（全ロール共通）。チーム集計・全社集計への切り替えは TBD #3 を参照。

#### 3.18.3 レーダーチャート（スキルバランス）

**目的**：エンジニアとしてのスキルの「型」（強み・弱みの偏り）を一目で把握する。

**データソース**

| 要素 | 取得元 |
|------|--------|
| 軸ラベル | `it_skill_categories`（`level = 1`）の分類1名 |
| 当年度の値 | ユーザーの今年度棚卸（`inventories`）に紐づく `it_skill_details` を分類1で集約し、`skill_levels.level_value` の**平均値**を算出 |
| 前年度の値 | 同上を前年度棚卸で算出 |

**表示要件**

- 軸：有効な分類1（`it_skill_categories.is_active = true`）の数だけ表示する
- 値：各軸 = その分類1に属する全スキルのうちユーザーが採点したものの `level_value` 平均（小数第1位）
  - 分類1配下のスキルを1件も採点していない場合、その軸の値は `0` として扱う
- 今年度データを**実線**、前年度データを**点線（半透明）**で重ねて表示する
  - 前年度棚卸データが存在しない場合は今年度のみ表示する
- **カスタムスキル**（`it_skill_id = NULL`）は分類1が特定できないため集計対象外とする
- **表示条件**：今年度のITスキル採点件数が0件の場合はグラフの代わりに「棚卸データがありません」を表示する
- **軸数の下限**：有効な分類1が2件以下の場合はレーダーチャートの代わりに「分類が不足しています（3件以上の分類1が必要です）」を表示する

#### 3.18.4 成長グラフ（時系列スコア推移）

**目的**：経年でのスキル成長の実感と、どの分野が伸びたかを把握する。

**データソース**

| 要素 | 取得元 |
|------|--------|
| 横軸（年度） | ユーザーが棚卸を提出済み（`status IN ('PENDING_GOAL', 'COMPLETED')`）の全年度。年度名（`fiscal_years.name`）で表示し、昇順に並べる |
| 縦軸（スコア） | 当該年度・分類1ごとの `level_value` **合計値** |
| 系列の色分け | 分類1ごとに固定色を割り当て |

**表示要件**

- 形式：**積み上げ棒グラフ**（stacked bar chart）
- 各バーを分類1ごとの合計スコアで積み上げ表示する
  - カスタムスキルは集計対象外とする
- 年度が1件のみでも棒グラフとして表示する
- **表示条件**：提出済み棚卸が1件も存在しない場合は「提出済みの棚卸データがありません」を表示する

#### 3.18.5 ヒートマップ（スキル詳細分布）

**目的**：スキルの網羅状況と強み・弱みを分類横断で一覧把握する。

**データソース**

| 要素 | 取得元 |
|------|--------|
| 縦軸（行） | `it_skill_categories`（`level = 1`）の分類1名 |
| 横軸（列） | 各分類1配下の `it_skill_categories`（`level = 2`）の分類2名。分類2を持たないスキルは「(分類なし)」列にまとめる |
| セル値 | その分類1×分類2の組み合わせに属するスキルのうち、ユーザーが今年度採点したものの `level_value` **平均値** |

**色の定義**

| 状態 | 条件 | 表示 |
|------|------|------|
| 未採点 | 該当スキルが存在するが採点なし、または分類1×分類2の組み合わせにスキルが存在しない | グレー（`#e5e5e5`） |
| 低（入門） | `level_value` が最大値の 1〜39% | 薄い青系 |
| 中（実践） | `level_value` が最大値の 40〜69% | 中程度の青系 |
| 高（熟練） | `level_value` が最大値の 70〜100% | 濃い青系 |

> 最大値は `skill_levels.level_value` の最大値（有効なレベルマスタ中の最大 `level_value`）を基準とする。

**表示要件**

- セルにマウスオーバー（またはタップ）すると、その分類2に属する個々のスキル名と採点値をツールチップで表示する
- カスタムスキルは集計対象外とする
- **表示条件**：今年度のITスキル採点件数が0件の場合は「棚卸データがありません」を表示する

#### 3.18.6 ラーニング・タイムライン（学習活動）

**目的**：資格取得・セミナー受講の学習活動と、今後の目標を一つの時間軸で把握する。

**データソース**

| イベント種別 | 取得元 | 時期 |
|------------|--------|------|
| 資格取得（実績） | `qualification_details.acquired_year_month`（NULL 以外） | 過去 |
| セミナー受講（実績） | `seminar_details.attended_year_month`（NULL 以外） | 過去 |
| 学習目標（予定） | 最新年度の `inventory_goals.target_period`（全 `goal_category`） | 未来 |

**表示要件**

- 形式：水平タイムライン。左端が古い日付、右端が新しい日付（未来）
- イベントを以下2つのレーン（行）に分けて表示する

  | レーン | 表示するイベント |
  |--------|----------------|
  | **上段（成果）** | 資格取得（実績）・学習目標のうち `goal_category = 'QUALIFICATION'` |
  | **下段（活動）** | セミナー受講（実績）・学習目標のうち `goal_category IN ('IT_SKILL', 'AD')` |

- 実績イベント（過去）と目標イベント（予定）はアイコン・色で区別する
  - 実績：塗りつぶしアイコン（例：取得済み資格バッジ、受講済みセミナーバッジ）
  - 目標（`target_period` が今日以降）：枠線アイコン（予定）
  - 目標（`target_period` が今日より過去）：グレーのアイコン（未達成扱いとして表示。振り返りの `achievement_status` は参照しない）
- 各イベントにマウスオーバー（またはタップ）すると名称・日付の詳細をツールチップで表示する
- 表示範囲：全履歴期間（登録されているすべての実績）＋最新年度の目標。横スクロールで対応する
- **表示条件**：実績・目標ともにイベントが0件の場合は「学習イベントがありません」を表示する

#### 3.18.7 データ集計ルール（共通）

- 各グラフで使用する `level_value` は `it_skill_details.skill_level_id` → `skill_levels.level_value` で解決する
- 削除済みのITスキルマスタ（`it_skills.is_active = false`）に紐づく棚卸明細は集計に**含める**（過去の棚卸実績の整合性保持のため）
- 削除済みの分類（`it_skill_categories.is_active = false`）については、その分類に属するスキルを「(削除済み分類)」として集計に含める
- カスタムスキル（`it_skill_id = NULL`）はすべてのグラフ集計から**除外**する

#### 3.18.8 バックエンド API 要件

グラフデータはフロントエンドでの集計を行わず、以下の専用エンドポイントからJSON形式で取得する。

| エンドポイント | 説明 |
|----------------|------|
| `GET /api/charts/radar` | レーダーチャート用データ（今年度・前年度の分類1別平均スコア） |
| `GET /api/charts/growth` | 成長グラフ用データ（年度別・分類1別スコア合計） |
| `GET /api/charts/heatmap` | ヒートマップ用データ（今年度の分類1×分類2別平均スコア） |
| `GET /api/charts/timeline` | タイムライン用データ（全年度の資格・セミナー実績と最新年度の目標一覧） |

- 各エンドポイントは JWT 認証を必須とし、ログインユーザー自身のデータのみ返す（Phase 1）
- レスポンスは集計済みの値を返し、フロント側での集計処理は行わない
