# 共通レイアウト定義

画面ID: COMMON
概要: 全画面共通のヘッダーおよびロール別ナビゲーションバーの定義

---

## 共通ヘッダー

```
┌──────────────────────────────────────────────────────────────────────────────┐
│  [ロゴ]  Skilize       ...ナビゲーション...       田中 太郎（一般）  [パスワード変更]  [ログアウト]  │
└──────────────────────────────────────────────────────────────────────────────┘
```

- 右側の **ユーザー名** には「（管理者）」「（TL）」「（一般）」のロールラベルが付く
- **パスワード変更** ボタンは `userId === 'admin'` のユーザーには表示されない
- **ログアウト** ボタンは全員に表示される

---

## ナビゲーションバー（ロール別）

### 一般ユーザー（GENERAL）

```
┌──────────────────────────────────────────────────────────────────────────────┐
│  [ロゴ]  Skilize    ダッシュボード          田中 太郎（一般）  [パスワード変更]  [ログアウト]  │
└──────────────────────────────────────────────────────────────────────────────┘
```

### TL（チームリーダー）

```
┌──────────────────────────────────────────────────────────────────────────────┐
│  [ロゴ]  Skilize    ダッシュボード    チーム照会       山田 花子（TL）  [パスワード変更]  [ログアウト]  │
└──────────────────────────────────────────────────────────────────────────────┘
```

### 管理者（ADMIN）

```
┌──────────────────────────────────────────────────────────────────────────────┐
│  [ロゴ]  Skilize    ダッシュボード    チーム照会    管理 ▾       管理者さん    [ログアウト]  │
└──────────────────────────────────────────────────────────────────────────────┘
                                                        │
                                             ┌──────────┴──────────────┐
                                             │ 全ユーザー照会          │
                                             ├─────────────────────────┤
                                             │ 年度マスタ              │
                                             ├─────────────────────────┤
                                             │ レベルマスタ            │
                                             ├─────────────────────────┤
                                             │ ITスキルマスタ          │
                                             ├─────────────────────────┤
                                             │ 参考資格マスタ          │
                                             ├─────────────────────────┤
                                             │ ADマスタ                │
                                             ├─────────────────────────┤
                                             │ ユーザー管理            │
                                             └─────────────────────────┘
```

> 管理者（`userId === 'admin'`）はパスワード変更ボタンが表示されない。  
> 「管理▾」ドロップダウンはクリックで開閉する。ページ遷移時に自動で閉じる。

## ルーティング構成（ロール別アクセス制御）

| パス | ページ | アクセス制御 |
|---|---|---|
| `/login` | ログイン | 未認証 |
| `/change-password` | 初回パスワード変更 | 全員（初回必須） |
| `/` | ダッシュボード | 全員（要認証） |
| `/inventory/:id` | 棚卸入力 | 全員（要認証） |
| `/inventory/:id/comparison` | 前年度比較 | 全員（要認証） |
| `/inventory/:id/goal-review` | 前回目標の振り返り | 全員（要認証） |
| `/inventory/:id/goals` | 目標設定 | 全員（要認証） |
| `/inventory/history` | 棚卸履歴 | 全員（要認証） |
| `/settings/password` | パスワード変更（マイページ） | 全員（要認証） |
| `/team` | チーム照会 | TL / ADMIN |
| `/team/:userId` | メンバー詳細 | TL / ADMIN |
| `/admin/users-inquiry` | 全ユーザー照会 | ADMIN |
| `/master/fiscal-years` | 年度マスタ管理 | ADMIN |
| `/master/skill-levels` | レベルマスタ管理 | ADMIN |
| `/master/it-skills` | ITスキルマスタ管理 | ADMIN |
| `/master/qualifications` | 参考資格マスタ管理 | ADMIN |
| `/master/ad-seminars` | ADマスタ管理 | ADMIN |
| `/master/users` | ユーザー管理 | ADMIN |

> バックエンドAPIは一部エンドポイントでTL/ADMINを許可しているが、フロントエンドUIへのナビゲーション（マスタ管理）はADMINのみに制限されている。

---

## 備考

- アクティブなナビゲーション項目は `.active` クラスで強調表示する
- 「管理▾」ドロップダウンはそのパス配下にいる場合もアクティブ扱いになる
- ヘッダーは全画面固定表示（スクロール時も追従）
- 棚卸操作（入力・照会）はダッシュボードから行う（NavBarに「棚卸を入力する」ボタンはない）
