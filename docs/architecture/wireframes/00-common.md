# 共通レイアウト定義

概要: 全画面共通のヘッダーおよびロール別ナビゲーションバーの定義

## ナビゲーションバー（ロール別）

## 備考

- アクティブなナビゲーション項目は下線またはハイライトで強調表示する
- ドロップダウンメニュー（管理▼）はホバーまたはクリックで展開する
- ヘッダーは全画面固定表示（スクロール時も追従）
