# マスタ管理画面 ワイヤーフレーム

> **ロール制限**: マスタ管理ページ（SCR-009〜SCR-018）はフロントエンドのルーティングで **ADMIN のみ** に制限されている。  
> バックエンドAPIは一部エンドポイント（ITスキル・資格・ADセミナー・各分類・レベル）で TL/ADMIN を許可しているが、現在のUIでは ADMIN しかアクセスできない。  
> 全マスタ管理画面の NavBar は「ダッシュボード | チーム照会 | 管理▾（アクティブ）」（ADMIN ナビ）。
