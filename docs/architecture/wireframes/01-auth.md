画面名: ログイン
概要: システムへのログイン画面。ユーザーIDとパスワードで認証を行う。

│                                                                              │

│                  └────────────────────────────────────┘                     │

### 入力項目

| 項目         | 種別           | 必須 | 備考             |

| パスワード   | パスワード入力 | 必須 | 入力値マスク表示 |

## パスワード変更（初回ログイン強制）

画面ID: SCR-001-B
画面名: 初回パスワード変更
概要: 初回ログイン時に強制表示される。変更が完了するまで他の操作は一切不可。

```
┌──────────────────────────────────────────────────────────────────────────────┐
│                                                                              │
│                           [ロゴ]  Skilize                                   │
│                       ITスキル棚卸管理システム                               │
│                                                                              │
│                  ┌────────────────────────────────────┐                     │
│                  │                                    │                     │
│                  │  ⓘ 初回ログインのため、パスワードを │                     │
│                  │    変更してください                 │                     │
│                  │                                    │                     │
│                  │  新しいパスワード                   │                     │
│                  │  [________________________________] │                     │
│                  │                                    │                     │
│                  │  新しいパスワード（確認）           │                     │
│                  │  [________________________________] │                     │
│                  │                                    │                     │
│                  │  ※ 8文字以上、英数字記号を含めて   │                     │
│                  │    ください                         │                     │
│                  │                                    │                     │
│                  │      [ パスワードを変更する ]        │                     │
│                  │                                    │                     │
│                  └────────────────────────────────────┘                     │
│                                                                              │
│  ※ パスワード変更が完了するまで、他の操作はできません                        │
│                                                                              │
└──────────────────────────────────────────────────────────────────────────────┘
```

### 入力項目

| 項目                       | 種別           | 必須 | 備考                                         |
|----------------------------|----------------|------|----------------------------------------------|
| 新しいパスワード           | パスワード入力 | 必須 | 強度要件（8文字以上・英数字記号含む）         |
| 新しいパスワード（確認）   | パスワード入力 | 必須 | 上記と一致するか確認                         |

### バリデーション・エラー表示

```
                  ┌────────────────────────────────────┐
                  │  新しいパスワード                   │
                  │  [________________________________] │
                  │  ※ 8文字以上で入力してください     │  ← エラーメッセージ
                  │                                    │
                  │  新しいパスワード（確認）           │
                  │  [________________________________] │
                  │  ※ パスワードが一致しません         │  ← エラーメッセージ
                  └────────────────────────────────────┘
```

### 変更完了後

- ダッシュボード（SCR-002）へ自動遷移する
