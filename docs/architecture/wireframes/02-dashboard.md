## SCR-002: ダッシュボード

画面ID: SCR-002
画面名: ダッシュボード
概要: ログイン後のトップ画面。当年度の棚卸ステータスと操作ボタン、スキル可視化グラフ、AIキャリア分析結果を表示する。棚卸の入力・照会はこの画面を起点として行う（NavBarに「棚卸を入力する」「照会する」ボタンは存在しない）。

### AIキャリア分析 ステータス別表示

| ステータス | 表示内容 |
|---|---|
| `PENDING` / `PROCESSING` | 「AIキャリア分析を準備中です...」（スピナーまたはメッセージ） |
| `COMPLETED` | 分析結果（総括・強み・成長領域・フィット感・ネクストステップ） |
| `FAILED` | エラーメッセージ |

> AIキャリア分析は棚卸提出時（`PENDING_GOAL` 遷移後）に非同期で自動起動される。  
> 分析が存在しない場合（初回棚卸等）はセクション自体が非表示。

---

### 棚卸ステータス別ボタン表示

| ステータス | 表示ボタン |
|---|---|
| 未作成 | 「棚卸を開始する」（→ 新規棚卸作成後に棚卸入力ページへ遷移） |
| `DRAFT` | 「棚卸を続ける」（→ 棚卸入力ページへ） |
| `PENDING_GOAL` | 「棚卸を続ける」（→ 目標設定ページへ） |
| `COMPLETED` | 「棚卸を確認する」（→ 棚卸入力ページ：読み取り確認モード） |

「過去の棚卸を確認する」は全ステータス共通で表示（→ `/inventory/history`）。

---

## ステータス表示仕様

| ステータス       | 説明                       |
|------------------|----------------------------|
| 未作成           | 当年度棚卸なし             |
| `DRAFT`          | 入力中（一時保存状態）     |
| `PENDING_GOAL`   | 棚卸提出済み・目標設定未完了 |
| `COMPLETED`      | 目標設定まで完了           |

---

## スキル可視化グラフ一覧

| グラフ名 | コンポーネント | データ取得 API | 表示条件 |
|---|---|---|---|
| スキルバランス（レーダー） | `RadarChartCard` | `GET /api/charts/radar` | 分類1が3件以上 |
| スキル成長推移（棒グラフ） | `GrowthChartCard` | `GET /api/charts/growth` | 提出済み棚卸が1件以上 |
| スキルマップ（ヒートマップ） | `HeatmapChartCard` | `GET /api/charts/heatmap` | 当年度棚卸あり |
| 活動タイムライン | `TimelineChartCard` | `GET /api/charts/timeline` | 常時（データなし時は空表示） |

- グラフデータは並列リクエストで取得する
- グラフはデータが存在しない場合、空状態メッセージを表示する

タイムライン イベント種別:

| イベント種別 | レーン | 説明 |
|---|---|---|
| `QUALIFICATION` | `ACHIEVEMENT` | 資格取得（実績） |
| `AD_SEMINAR` | `ACTIVITY` | ADセミナー参加（実績） |
| `FREE_SEMINAR` | `ACTIVITY` | フリーセミナー参加（実績） |
| `GOAL_IT_SKILL` | `ACHIEVEMENT` | ITスキル目標（未来） |
| `GOAL_QUALIFICATION` | `ACHIEVEMENT` | 資格目標（未来） |
| `GOAL_AD` | `ACTIVITY` | AD目標（未来） |

凡例:
- `●` 実線ドット = 実績イベント（過去）
- `◎` 破線ドット = 目標イベント（未来）
