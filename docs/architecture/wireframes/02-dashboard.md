## SCR-002: ダッシュボード

画面ID: SCR-002
画面名: ダッシュボード

## ステータス表示仕様

| ステータス       | 表示色     | アイコン | 説明                       |
|------------------|------------|----------|----------------------------|
| DRAFT            | グレー     | ●        | 一時保存中                 |
| PENDING_GOAL     | オレンジ   | ⚠        | 提出済み・目標設定未完了   |
| COMPLETED        | グリーン   | ✓        | 完了                       |

---

## グラフ表示仕様

| グラフ                 | コンポーネント         | ライブラリ       | データ取得 API          |
|------------------------|------------------------|------------------|------------------------|
| スキルバランス         | RadarChartCard         | recharts         | GET /api/charts/radar  |
| スキル成長推移         | GrowthChartCard        | recharts         | GET /api/charts/growth |
| スキルヒートマップ     | HeatmapChartCard       | カスタム CSS     | GET /api/charts/heatmap |
| ラーニングタイムライン | TimelineChartCard      | カスタム CSS     | GET /api/charts/timeline |

各グラフの詳細なレスポンス仕様は [docs/architecture/api/06-charts.md](../api/06-charts.md) を参照。
