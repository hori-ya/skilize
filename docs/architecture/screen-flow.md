## 2. 認証フロー詳細

```mermaid
flowchart TD
    A([ログイン送信]) --> B{認証成功?}
    B -->|失敗| A
    B -->|成功| C{is_initial_password\n= true?}
    C -->|Yes\n初回ログイン| D["パスワード変更画面\n（変更完了まで他操作不可）"]
    D --> E
    C -->|No| E{当年度棚卸\nステータス確認}
    E -->|"PENDING_GOAL\n（棚卸提出済み・目標未完了）"| P{goal_review_completed_at\n= NULL かつ前年度目標あり?}
    P -->|"Yes"| Q["SCR-019\n前回目標の振り返り\n（強制遷移）"]
    P -->|"No"| F["SCR-005\n目標設定\n（強制遷移）"]
    Q --> F
    E -->|"DRAFT / COMPLETED\nまたは当年度データなし"| G["SCR-002\nダッシュボード"]
```

## 3. 棚卸・目標設定フロー詳細

```mermaid
flowchart TD
    A(["SCR-002\nダッシュボードから開始"]) --> B

    B["SCR-003 棚卸入力\n(ITスキル / 資格 / セミナー タブ切替)"]

    B -->|"一時保存\n(DRAFT)"| C
    B -->|"提出\n(PENDING_GOAL へ遷移)"| C

    C{"SCR-004 前年度比較・振り返り\n前年度データあり?"}
    C -->|"初回棚卸\n（前年度データなし）"| G
    C -->|"2年目以降"| D

    D["採点変化スキルを強調表示\n備考が空の場合は入力を促す\n（任意）"]
    D -->|"備考を追記して保存"| D
    D -->|"そのまま次へ"| G

    G{"操作種別は?"}
    G -->|"一時保存後\n編集を続ける"| B
    G -->|"一時保存後\n中断する"| H["SCR-002\nダッシュボード\n(DRAFT)"]
    G -->|"提出後"| J{前年度目標あり\nかつ振り返り未完了?}
    J -->|"Yes"| K["SCR-019\n前回目標の振り返り"]
    J -->|"No"| E
    K --> E

    E["SCR-005 目標設定\n(PENDING_GOAL)"]
    E -->|"一時保存\nPENDING_GOAL 維持"| E

    E --> F{"件数チェック\nITスキル/資格 ≥ 1件\nAD = 2件"}
    F -->|"不足あり\nエラー表示・ブロック"| E
    F -->|"充足\n完了ボタン押下"| I["SCR-002\nダッシュボード\n(COMPLETED)"]
```
